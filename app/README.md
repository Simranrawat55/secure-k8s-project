# Security Hardened Kubernetes Platform

## Project Overview

This project demonstrates a security-hardened Kubernetes platform
for deploying a containerized application.

## Objectives

- Containerize a Python Flask application
- Deploy the application on Kubernetes
- Implement Kubernetes security controls
- Configure RBAC and ServiceAccounts
- Implement NetworkPolicies
- Use Kubernetes Secrets securely
- Run containers as non-root users
- Apply CPU and memory limits
- Scan container images for vulnerabilities
- Build a CI/CD pipeline
